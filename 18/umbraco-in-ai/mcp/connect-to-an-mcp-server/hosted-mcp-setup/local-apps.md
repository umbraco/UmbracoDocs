# Local Apps

Claude Code, Claude Desktop, Cursor, and GitHub Copilot (via Visual Studio Code) run on your machine. To use a hosted Umbraco MCP server, you point the app at your hosted MCP URL through a config file or CLI command. The app itself stays local — only the MCP server is remote.

* [Claude Code](claude-code.md)
* [Claude Desktop](claude-desktop.md)
* [Cursor](cursor.md)
* [GitHub Copilot](github-copilot.md)

{% hint style="info" %}
The examples in these guides use the Editor MCP Server. The same connection method applies to any hosted Umbraco MCP server — see [Finding Your MCP URL](README.md#finding-your-mcp-url) for the Developer MCP hostname.
{% endhint %}

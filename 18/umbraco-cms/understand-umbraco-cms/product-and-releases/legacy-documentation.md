# Legacy Documentation

This documentation covers the currently supported versions of Umbraco CMS. For legacy or End-of-Life (EOL) versions, use the resources below.

[Learn more about Umbraco's Long-Term Support and EOL policy.](https://umbraco.com/products/knowledge-center/long-term-support-and-end-of-life/)

## [End-of-Life versions on GitHub](https://github.com/umbraco/UmbracoDocs/tree/umbraco-eol-versions)

When a major version of Umbraco CMS reaches EOL, its documentation is unpublished one to three months later.

Documentation for all EOL versions remains available on the [UmbracoDocs GitHub repository](https://github.com/umbraco/UmbracoDocs/tree/umbraco-eol-versions).

## Legacy Umbraco: Versions 7 and 8

The documentation for Umbraco versions 7 and 8 is available on [GitHub](https://github.com/umbraco/UmbracoDocs/blob/legacy-docs/README.md).

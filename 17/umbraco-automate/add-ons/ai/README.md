# AI

The AI add-on bridges Umbraco Automate and [Umbraco.AI](https://docs.umbraco.com/ai-in-umbraco). It adds triggers that fire on AI agent lifecycle events. It also adds actions that invoke an AI agent, transcribe audio, or ask an experimental Decision question.

## What It Adds

| Type | Items |
| ---- | ----- |
| Triggers | AI Agent Run Completed, AI Agent Run Failed, AI Agent Request |
| Actions | Run AI Agent, Transcribe Audio, Ask Yes/No, Ask Pick-One, Ask Score, Ask Questions (experimental) |

# Release Notes

This article summarizes the changes introduced in each version of Umbraco Engage AI.

The major version of Umbraco Engage AI follows the major version of Umbraco CMS. Check the [Installation](getting-started/installation.md) article for the Umbraco Engage version each release requires.

## Release History

#### [18.0.0](https://www.nuget.org/packages/Umbraco.Engage.AI/18.0.0) (September 21st 2026)

* Added support for Umbraco CMS 18. This version requires Umbraco Engage 18.1.0 or newer.
* The tools are the same as in 17.0.0.

#### [17.0.0](https://www.nuget.org/packages/Umbraco.Engage.AI/17.0.0) (September 17th 2026)

* First release of Umbraco Engage AI for Umbraco CMS 17. This version requires Umbraco Engage 17.4.0 or newer.

# Web-Hosted Platforms

ChatGPT and Claude.ai run in the browser and already act as a hosted service themselves. Instead of a config file, you add the MCP server through the platform's own settings — ChatGPT calls this a plugin, Claude.ai a connector.

* [Claude.ai](claude-ai.md)
* [ChatGPT](chatgpt.md)

{% hint style="info" %}
These settings UIs change often. The guides above describe the concept and link to the vendor's current documentation. They don't promise an exact, unchanging menu path.
{% endhint %}

{% hint style="info" %}
The examples in these guides use the Editor MCP Server. The same connection method applies to any hosted Umbraco MCP server — see [Finding Your MCP URL](README.md#finding-your-mcp-url) for the Developer MCP hostname.
{% endhint %}
